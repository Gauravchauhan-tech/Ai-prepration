AI Job Preparation

An AI-powered web application designed to help students and job seekers prepare for technical interviews, improve their skills, and practice answering interview questions.

Features

- AI-powered interview preparation.
- Technical interview questions and answers.
- Practice for different job roles.
- User-friendly interface for learning and preparation.
- Full-stack web application with a frontend and backend.

Tech Stack

Frontend: React.js, HTML, CSS, JavaScript

Backend: Node.js, Express.js

Database: MongoDB

Tools: Git, GitHub, VS Code

Project Structure

Ai-prepration/
├── frontend/
├── backend/
├── package.json
└── README.md

The folder structure may vary depending on the project setup.

Installation and Setup

1. Clone the repository

git clone https://github.com/Gauravchauhan-tech/Ai-prepration.git
cd Ai-prepration

2. Install dependencies

Install the dependencies for the frontend and backend according to the project structure.

npm install

3. Configure environment variables

Create a ".env" file in the backend directory and add the required configuration, such as the MongoDB connection string and AI API key.

MONGO_URI=your_mongodb_connection_string
AI_API_KEY=your_ai_api_key

Use the actual environment variable names required by your application.

4. Run the application

Start the backend and frontend servers using the scripts defined in your project.

npm start
